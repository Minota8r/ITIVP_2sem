# ITIVP2

Лабораторные работы по дисциплине «Интернет-технологии и веб-программирование».

## Структура

```
lab01/   — лабораторная работа №1
lab02/   — лабораторная работа №2
...
```

Каждая работа лежит в отдельной папке и содержит свой `README.md` с заданием
и кратким описанием реализации.

## Запуск

Статические работы открываются напрямую в браузере (`index.html`).
Для работ с локальным сервером — инструкции в README соответствующей папки.
